# 页面与版式

## 默认结构

参考文件10位销售、29页。默认由19页公共内容加N位销售个人页组成；缺少模块数据时先核实需要保留还是删减，不套旧数。用户要求的页数或章节优先。

| 顺序 | 内容 | 必须注意 |
|---|---|---|
| 1–2 | 封面、目录 | 更新门店和月份；目录主章节及页码居中，不加长说明栏 |
| 3 | 经营结果总览 | 开票、利润量、总毛利、单车毛利等核心指标；字号大，无无关宣传照片 |
| 4 | 销量目标与交付节奏 | 目标取已确认数据；完整日趋势并标零销量日期 |
| 5–6 | 集团/区域、所列经销商对标 | 不扩大市场覆盖范围，不混用店内数量 |
| 7–8 | 渠道、首次/多次进店转化 | 写实际数量与比率；不填泛泛的经营建议 |
| 9 | 利润构成与收益质量 | 收支与盈利；有明细才列车型/个人单车精品扣减 |
| 10 | 车型结构与盈利 | 全部有销量车型、销量、毛利、单车毛利；过多可分栏或经授权分页 |
| 11 | 团队业绩与效率 | 小组销量/毛利/加权单车毛利；每人单车及总毛利；点名达到指定阈值的人 |
| 12–13 | 接待总体、接待个人对比 | 总体数据和有依据的共性问题；个人对比最后一列小于70分条数 |
| 14起 | 每位销售个人页 | 按当期原分组顺序，每人恰好一页；不展示分组名称 |
| 个人页之后 | 金融保险、延保、无忧、问题汇总、下月目标、结尾 | 目标页只列目标；不自动增加责任人/行动方法/时间表 |

## 个人页的固定内容

标题：`姓名｜X月个人复盘`。保留当期销售的真实姓名，不从示例补人。

上方经营指标：利润核算销量、总毛利、单车毛利，必要时显示与团队均值及已确认目标的差距。团队均值不是个人考核目标。

左侧接待成绩：

```
X月接待成绩
本月平均 XX.XX分    XX条记录
上月均分 XX.XX分，本月 ±X.XX分
80分及以上 X/X条，占X.X%
低于60分 X/X条，占X.X%
85分及以上 X条
本月分数范围：X至X分
```

右侧三块业务文字，例如：

```
延保｜渗透率XX.X%｜第X名（符合高亮条件才必须列名次）
转介绍X人，有效对接X人；成交X单 / 基数X台
无忧｜渗透率XX.X%｜并列第X名
推荐X人；成交X单 / 基数X台
银行｜渗透率XX.X%｜第X名
商业银行X单 / 开票X台
```

字段按真实来源选取，不为填满版面造出缺失字段。三项业务用文字，不画明细表格。渗透率前三、后二按数据规则标红/黑并列实际名次。删除“较好表现”“不足与波动”“10月改善动作”等旧栏，除非用户明确重新要求。不能删掉此前保留的接待成绩，只剩85分条数。

## 模板几何与字体

- 16:9，参考画布1280×720；优先微软雅黑，文字与图表保持原生可编辑。
- 所有内页标题移到BYD右侧，保持logo及固定品牌线条。参考标题文字起点约x207、y20，高约39；红底从约x200开始。封面和结尾沿用各自版式。
- 标题白色粗体约24px，**上下居中**。红底长度随实际文字测量宽度加约24px边距调整，不能所有标题用同一个长红框；标题文本框留约8px余量。中文、数字、英文混排须实际测量和渲染检查。
- 主内容大致x72–1208、y135–662，底部品牌线约y675，保持留白。
- 普通正文约22–26px，辅助文字约17–20px；KPI约36–44px。经营总览可用标签22、数字44、说明20。不要靠不断缩小字号容纳内容。
- 默认主红`#C00000`，正文`#252525`，中性灰`#666666`；后二渗透率用`#000000`。保持原图表语义颜色。
- 所有有销量车型可用两张并列表；列宽、表头、汇总行一致。没有销量的车型不为凑列表保留。
- 目录保留主章节和页码并整体居中，删除多余解释列。更改页序后同步目录、页码、交叉引用。
- 不加入和本月内报无关的集团外宣图片；不新增数据来源脚注、操作说明或“本页用于……”之类正文。
