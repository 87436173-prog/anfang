# 开发说明

## 架构与代码入口

本项目采用原生 HTML/CSS/JavaScript，无前端框架、构建步骤或业务后端。保留单文件结构即可发布，不需要引入框架来修改费率或字段。

在 `index.html` 中搜索以下名称定位代码，避免依赖容易随修改变化的行号：

| 搜索项 | 职责 |
| --- | --- |
| `<style>`、`@media` | 电脑/手机布局，断点 800px、480px |
| `id="cost-data"` | 内嵌 JSON 商品库，每条仅含 `sku`、`name`、`cost` |
| `computeAtPrice` | 按给定售价计算费用和利润；毛利与定价模式共用 |
| `calculate` | 输入校验、反推价格、复核、结果展示 |
| `setMode` | 毛利/定价模式切换，保留原输入售价 |
| `renderSiteText`、`site` 的 change 事件 | 站点名称、预设费率、币种与活动选项 |
| `t`、`applyLanguage`、`data-en` | 动态/静态中英文文案 |
| `renderCostResults` | SKU/商品名搜索及分页展示 |
| `refreshRates`、`showRateForSite` | 汇率获取、报价日期和失败提示 |

## 金额与公式

所有费用先统一为人民币，计算使用完整精度。下面各费率是小数，例如 18.88% 写成 0.1888。

| 符号 | 含义 |
| --- | --- |
| P、e | 当地币售价；人民币/当地币汇率 |
| C、H | 人民币商品总成本；人民币贴单费 |
| S | 固定平台费（当地币输入，计算前乘 e） |
| p、a、f、l | 平台基础综合费率、联盟佣金率、有效活动费率、损耗率 |
| r、v | VAT 税率；含税价中的税占比 v=r/(1+r) |
| d、B | PayLater 额外费率；买家支付运费（当地币） |
| R、m | 销售额/广告费 ROI；目标利润率 |

```text
销售额 Y = P × e
平台基础费 = Y × p
销售 VAT = Y × v
联盟佣金 = (Y − 销售 VAT) × a
活动费 = Y × f
PayLater 差额 = (P + B) × e × d
损耗 = Y × l
扣广告前利润 M = Y − 上述各费 − S − C − H
广告费 = R=0 时为0，否则 Y/R
利润 = M − 广告费
利润率 = 利润/Y
最低保本 ROI = Y/M，仅 M 大于容差时有效
```

英国以外 v=0。英国联盟佣金使用不含 VAT 商品价；利润率分母仍是输入的含税售价对应销售额。ROI=0 表示没有广告成本；毛利模式留空 ROI 时只显示保本 ROI，定价模式必须填写 ROI。

反推售价（金额须先换成人民币）：

```text
q = R=0 时为0，否则1/R
D = 1 − p − d − a×(1−v) − f − v − l − q − m
P = (C + H + S + B×e×d) / (D×e)
```

正固定成本且分母非正时不能达标；固定成本全为0时不输出唯一价格。售价按当地币0.01向上取整，再调用 `computeAtPrice` 检查毛利率不低于目标。普通金额、百分比、ROI显示1位小数；定价售价显示2位。显示值不可回填替代内部精度。

## 数据、汇率和语言

- 商品库1228条，成本为人民币单件成本。查询只带入单件成本；多件、赠品、组合装需手动填写整单总成本。
- 改商品库只替换 `cost-data` JSON，保持字段类型和SKU唯一，名称原文保留。JSON内若含 `</script>` 必须转义为 `<\/script>`，避免提前结束脚本标签。
- 测试包含当前1228条的快照断言；合法增减SKU后应同步更新预期数量，并核对数据字段和唯一性。
- 汇率接口 `https://open.er-api.com/v6/latest/CNY` 返回每人民币可兑外币数，代码取倒数。打开页面自动获取，按钮重试；报价非当日时明确提示。失败可沿用本次打开已成功获取的报价，没有跨次打开的持久缓存。
- 汇率是日度参考价，不是逐秒行情或实际结汇价。联网刷新不会自动更新平台费用或商品库。
- 静态文字用 `data-en`（占位符用 `data-en-placeholder`，无障碍文案用 `data-en-aria-label`），动态文字用 `t(中文,英文)`；新增字段须同时覆盖两种语言。语言切换保留输入，重新计算结果。

## 已知限制

基础百分比是本店历史综合估算，不是每SKU精确的官方费率引擎。未自动处理单件封顶（菲运费服务费、泰成长费、马来BXP等）、阶梯费用、店铺减免、退款完整生命周期、可抵扣进项VAT、多商品税率或所有运费补贴。英国Smart Promotion按售价分摊估算。活动日须用户按平台窗口手动选择。没有账号权限、后台商品管理、自动费用更新或自动部署。

升级时优先保持现有单文件结构，只修改所需字段与对应公式；费率变动先确认计费基数、固定/比例属性、含税与否和适用范围，避免把某项差额叠加两次。
