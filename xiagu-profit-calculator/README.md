# 毛利计算器 / Profit Calculator

适用于菲律宾、马来西亚、泰国和英国的单文件商品毛利与定价工具，支持电脑与手机、中英切换、商品成本查询、联网汇率，以及按目标毛利率反推销售价。

[打开已发布计算器](https://xiagu-2026-d3ghwv17l06901ed7-1499999493.tcloudbaseapp.com/index.html)

## 直接使用

下载本文件夹后，用浏览器打开 `index.html` 即可，无需安装或构建。汇率获取需要联网；网络不可用且本次打开未获取有效汇率时，不会输出利润。商品成本为内置快照，不会自动同步 ERP。

此公开源码包含 **1228 条真实商品名称、SKU 和成本**，由所有者确认公开分享。页面没有登录功能。

## 接手开发

1. 阅读 [开发说明](DEVELOPMENT.md)，确认计算口径和已知限制。
2. 修改 `index.html`，它同时包含 HTML、CSS、JavaScript 和商品数据。
3. 在本文件夹内执行 `node tests/test-fees.cjs`，或执行 `npm test`。测试只使用 Node.js 内置模块，不需要先安装依赖。
4. 用浏览器人工检查手机宽度、语言切换、商品搜索、网络失败和结果滚动。
5. 按 [发布说明](DEPLOYMENT.md) 部署；修改 GitHub 文件不会自动更新腾讯云网页。

开发测试环境：Node.js 22 或更新版本。最终用户使用浏览器，无需 Node.js。

## 版本口径

本次源码交接日期：**2026-11-25**。应用最近一次费率修订：**2026-11-11**。交接打包未重新调查 11 月 25 日平台费率，不应将本项目费率理解为永久有效的官方统一费率。
