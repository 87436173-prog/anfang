# 客户意向等级口径（intention-level-2026-11-18-v1）

用户 2026-11-18 裁决原文：**"三天内订车的客户是H级，7天内订车的是A级，30天内订车的是B级，超过30天的算C级。看车不到10分钟就走的客户属于D级。"** 同日补充：**"已订车的客户属于O级"**，并明确 **"此项调整针对后续的录音"**（不回改历史报告）。

本版本自 2026-11-18 起为 `job.intention.level` 的唯一判定口径，优先于此前所有「高意向」「30天内成交」等模糊表述。**只对 2026-11-18 之后新评分的录音生效，历史报告不回溯。**

## 1. 分档

| 等级 | 判定标准（以本单接待日为第 0 天） | 典型证据 |
|---|---|---|
| **O** | 已订车、已成交 | 交定金并开收据、签合同、线上下单成功、订单验证码匹配、进入验车/交付流程 |
| **H** | 尚未下订，但明确 3 天内订车（当天/次日/第三天） | 「今天就定」「明天打款」「星期天订成」，且当日未完成付款或下单 |
| **A** | 明确 4–7 天内订车 | 约定本周内签约、7 天内下订或提车，但尚未下订 |
| **B** | 明确 8–30 天内订车 | 「这个月内」「月底前」「20 号左右」「下个月初」且落在 30 天内 |
| **C** | 超过 30 天，或未给出任何订车时间 | 「下个月」「明年初」「元月份」「回去商量」「比完价再说」而无具体日；纯了解性咨询 |
| **D** | 看车不到 10 分钟就离店 | 在店时长 < 10 分钟且无任何成交动作（以录音有效时长＋离店语判断，不含录音中断） |

## 2. 判定要点

1. **O 看动作，H 看承诺**：已交定金、已签合同、已线上下单 → O，不再看提车日期排到几天后；仅口头「就定了」但未付款、未下单 → 按承诺天数落 H/A/B。
2. **天数以客户自己的时间表述为准**；销售单方面催促（「你这两天早点订」）不单独作为客户承诺，销售与客户共同确认的日期（「15 号过来提车」）可作依据。
3. **没有时间表述一律 C**，不得因为「意向强」「谈到落地价」「加了微信」升到 B。C 是「超 30 天或时间不确定」的合并档。
4. **D 只看在店时长**：以录音有效时长与离店语为准；录音中途中断、设备故障、客户换场地继续谈的，不判 D，按实际意向落 O/H/A/B/C，并在 reason 注明无法确认在店时长。
5. **一次接待只有一个等级**，同一客户多段录音合并评估时取最高等级证据；不得因客户后来到店或改单而改写原单等级。
6. 等级只作客户分层与跟进排序，**不参与 100 分制计算、不影响档位与负激励、不影响任何加分项**。

## 3. 与原口径的差异（仅对后续录音执行）

- 原「已订车」常与 A/H 混用 → 统一 O。
- 原「属 30 天内成交」标 A → 统一 B（4–7 天才是 A）。
- 原「回去考虑」「加微信后续联系」「比价后再定」标 B → 统一 C（无时间表述）。
- 原「明年初／下个月／元月份」标 B → 统一 C（超 30 天）。
- 原「看车 6 分钟、拒绝加微信」仍标 C → 改判 D。

## 4. 执行

- 新评分在 `intention.reason` 末尾写明「按 intention-level-2026-11-18-v1 归 X 级（依据：…）」，`evidence` 必须含对应时间戳。
- `intention.level` 允许值：`O/H/A/B/C/D/待核实`，渲染脚本已支持 O。
- **历史报告不回溯**：2026-11-18 之前已 publish 的报告保持原等级，不重算、不重推。
