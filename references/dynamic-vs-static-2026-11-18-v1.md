# 动态讲解与静态讲解互斥计分（dynamic-vs-static-no-double-count-2026-11-18-v1）

用户 2026-11-18 裁决原文：**"试驾过程中的讲解属于动态讲解，不能作为静态讲解给分的依据。如果哪一段给了分，就不能作为其他项目给分的依据。"** 同日追加裁决：**"试驾环节的所有内容只作为 D 项的打分依据。"**

## 0. 总则（最高优先）

**试驾环节的所有内容，只作为 D 项的打分依据。** 客户上车后发生的一切——讲解、演示、客户体验、客户表达喜爱、销售承诺、随车问答、随车对比竞品、随车品牌宣讲——全部归 D2–D9，**不得计入 A、B、C、E、F、G 任何一项，也不得作为 A3/B8/B8coffee/C5bonus 等加分项的依据**。

唯一例外：客户在**试驾流程开始前**于展厅/展车旁/场地停车状态下的讲解与体验，以及**试驾结束返店后**在展厅、洽谈区的讲解与体验，仍属静态，可计 C 模块。

本版本自 2026-11-18 起为 C 模块与 D 模块取证的强制口径，优先于此前所有允许"试乘中体验""试驾中演示"计入 C5 呈现形式的写法。

## 1. 场景划分（按客户所处位置，不按录音文件）

| 类别 | 认定场景 | 可计入模块 |
|---|---|---|
| 静态讲解 | 展厅、展车旁、洽谈区、交付区；客户坐进**展厅展车**内触摸、调节、观看 | C2–C8 |
| 动态讲解 | 客户上车后的一切时段：试驾路线上的行驶、试乘副驾、场地试驾、试驾返程、车内静态功能介绍但车辆已处于试驾流程中 | D2–D9 |

判定要点：
- 以**客户是否已进入试驾/试乘流程并上车**为分界，不以录音文件切分。同一段接待录音里客户上车后的部分，虽然文件名不是"试驾专项"，也一律按动态处理。
- 试驾专员/销售在车内演示城市领航、拨片激活、自动泊车、加速刹车、隔音、底盘滤震、掉头半径实测，均属动态讲解。
- 展厅内客户坐进展车感受座椅、天幕、冰箱、小桌板、放倒成床、电尾门、空悬升降，属静态讲解，可计入 C5。
- 试驾前的车辆静态绕车、开门看后备箱（车未启动、客户未上车）属静态。

## 2. 互斥规则

1. **动态讲解不得作为 C 模块任何一项的给分依据**，包括但不限于 C3 关注点挖掘（车内追问）、C4 关注点回应（车内讲解）、C5 卖点演示（"试乘中客户坐副驾实际体验"）、C6 疑虑解答（行驶中答疑）、C8 品牌自信（车内宣讲）。
2. **静态讲解不得重复计入 D 模块**。D7/D8 的动态亮点须以试驾/试乘段原音为准，展厅段不能顶替。
3. **同一段原音只能支撑一个计分项**。同一个卖点、同一个演示动作、同一句讲解，只能在 C 或 D 其中一处得分，不得两处各计一次。
   - 模块内不适用互斥（原表本就是不同考核角度）：C4 考「是否回应客户关注点」、C5 考「卖点是否讲透」，同一段讲解可同时支撑两项；C6 是逐条问答汇总行，与其他项同窗不构成重复。此豁免仅限 C 模块内部，不得延伸到 C 与 D 之间。
4. **判重以"讲解内容/演示动作"为单位，不以时间窗重叠为准**：C2 车型推荐与 C5 闪充讲解可能同处 00:00–02:00，但内容不同，各自成立；C6 是逐条问答的汇总行，与其他项同窗不构成重复计分。反之，同一句"城市领航可拨片激活"即使分处两个时间窗，也只能计一次。
5. 若某段原音是某 C 项的唯一证据、但该段已被计入 D，则**C 项按无证据处理并降档**（该卖点不计、该关注点回应记 0），证据栏须写明"该段已计入 D 模块，按不重复计分不用于 C"。不得因为"讲得很好"保留原分。
6. 加分项同样受约束：C5bonus 须由静态段的"打动客户"证据支撑；试驾段的客户喜爱表达只能用于 D8（D8bonus 已停用，恒 0）。

## 3. 典型误判与正确做法

- 错：C5 记 4 分，卖点 2 写"呈现形式=试乘中客户坐副驾实际体验天眼B城市领航"，D2–D9 同时又按同一段试乘记 15/20。
  对：该卖点归 D7/D8 动态讲解，C5 只剩闪充一个卖点，记 2 分。
- 错：C4 证据写"试驾中让客户亲自掉头验证 5.2 米"，同时 D8 已按客户亲自驾驶记 9 分。
  对：掉头验证归 D；C4 若另有展厅内"打电话问产品经理得到 5.6 米、不标配后轮转向、报车长车宽"的独立证据，可保留 3 分，但须删除动态表述。
- 错：D7 记 3 分，理由引用的是展厅内静态绕车讲解。
  对：D7 无车辆行驶中的讲解证据则记 0 或按实际档降级。
